# MathCalc

Matrix / calculus / 3D-graphics / vector calculator with step-by-step solutions.
React + Vite, KaTeX rendering, Three.js viewers. Korean / English toggle.

## Develop

```bash
npm install
npm run dev      # http://localhost:5173
```

## Build

```bash
npm run build    # outputs to dist/
```

Deployed as a static site at `https://yanghyunw00.github.io/project/calc/`
(`base` is set to `/project/calc/` in `vite.config.js`; routing uses `HashRouter`).
